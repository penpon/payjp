# アクセス制御ポリシー — PCI DSS SAQ A Req 8

対象: 本サービスのシステムコンポーネント（Webサーバー、DBサーバー、CI/CD）へのアクセス  
最終更新: 2026-04-09  
次回レビュー: 2027-04-09

## 8.2.1 一意のユーザーID

- システムアクセスには個人に紐づく一意のIDを使用する
- SSH: 個人のSSH公開鍵（共有鍵の禁止）
- GitHub: 個人アカウント
- 1Password: 個人アカウント（チームVault経由）
- DB管理: 個人特定可能な接続のみ（アプリケーション用サービスアカウントは別途管理）

## 8.2.2 共有・汎用アカウントの管理

- 原則禁止
- 例外: アプリケーション用サービスアカウント（`api` サービスのDB接続）
  - 業務正当性: アプリケーションランタイム用
  - 使用範囲: Docker Compose内の api → db 接続のみ
  - クレデンシャル管理: 1Password Vault（`op run` 経由で注入）
- 共有アカウント使用時は管理者承認を記録する

## 8.2.5 退職者・離脱者のアクセス無効化

- 退職・プロジェクト離脱時は即日以下を実施:
  - SSH公開鍵の削除
  - GitHub リポジトリアクセスの削除
  - 1Password Vault からの除外
  - DB直接アクセス権の削除（該当する場合）
- 実施記録を残す

## 8.3.1 認証要素

全システムアクセスに最低1つの認証要素を使用:

| アクセス先 | 認証要素 | 種別 |
|---|---|---|
| サーバー（SSH） | SSH公開鍵 | 所持（Something you have） |
| GitHub | パスワード + 2FA | 知識 + 所持 |
| 1Password | マスターパスワード + デバイス認証 | 知識 + 所持 |
| DB（管理用） | SSH トンネル経由 + DB パスワード | 所持 + 知識 |

## 8.3.5 初回パスワード

- 初回パスワードは一意の値を設定する
- 初回ログイン時に変更を強制する
- メール・チャット等での平文パスワード共有を禁止する

## 8.3.6 パスワード複雑性

- 最低12文字
- 英字（大文字・小文字）と数字の両方を含む
- 適用先: SSH パスフレーズ、DB パスワード、1Password マスターパスワード
- アプリケーション・システムアカウント（Req 8.6管轄）は除く

## 8.3.7 パスワード履歴

- 直近4回のパスワードと同一のパスワードは使用不可

## 8.3.9 パスワードの定期変更

以下のいずれかを適用:
- **方式A**: パスワードを90日ごとに変更する
- **方式B**: アカウントのセキュリティ状態を動的に分析し、リアルタイムでアクセスを判定する

現行の採用方式: **方式A**（90日ローテーション）

| 対象 | ローテーション間隔 | 管理場所 |
|---|---|---|
| POSTGRES_PASSWORD | 90日 | 1Password |
| SSH パスフレーズ | 90日 | ローカル |
| PAYJP_WEBHOOK_TOKEN | 90日 | 1Password + PAY.JP ダッシュボード |
| DISCORD_BOT_TOKEN | 90日 | 1Password + Discord Developer Portal |

## 適用除外

- MFAが適用されているシステム（GitHub 2FA等）では 8.3.9 は不適用（公式Applicability Notes準拠）
- エンドユーザー（Discord OAuth利用者）は本ポリシーの対象外
