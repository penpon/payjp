# ASVスキャン対応方針 — PCI DSS SAQ A Req 11.3.2 / 11.3.2.1

最終更新: 2026-04-09

## 要件

- **11.3.2**: PCI SSC認定ASV（Approved Scanning Vendor）による外部脆弱性スキャンを四半期ごとに実施
- **11.3.2.1**: 重大変更後に外部脆弱性スキャンを実施（CVSS 4.0以上を解消）

## 本プロジェクトのインフラ構成

| コンポーネント | ホスティング | 外部公開 |
|---|---|---|
| フロントエンド（SPA） | Cloudflare Pages | はい（www.and--line.com） |
| バックエンドAPI | 自己管理VPS（Docker） | はい（api.and--line.com、nginx経由） |
| PostgreSQL | 自己管理VPS（Docker、ポート非公開） | いいえ（localhost のみ） |

## 判断

バックエンドAPIが自己管理VPS上で稼働し、外部公開されているため、**ASVスキャンは必要**と判断する。

### 初回アセスメントの緩和措置（SAQ A p.18 Applicability Notes）

> "初回PCI DSSアセスメントでは、12ヶ月間に4回のパススキャンは不要。以下を確認すればよい:
> 1. 直近のスキャンがパスしていること
> 2. 四半期スキャンのポリシー・手順が文書化されていること
> 3. スキャン結果で検出された脆弱性が修正済みであること"

## 対応計画

### Go-Live前（2026-04-20）

1. **PAY.JPに確認**: 加盟店としてASVスキャンが必須かどうか（日本のクレジットカード・セキュリティガイドラインの非保持化加盟店に対する要件を確認）
2. **ASV選定**: 必要と判断された場合、以下から選定
   - Qualys（PCI SSC認定ASV）
   - Tenable / Nessus
   - Rapid7 InsightVM
3. **初回スキャン実施**: Go-Live前にパススキャンを取得

### 運用開始後

| 項目 | スケジュール |
|---|---|
| 定期ASVスキャン | 四半期（1月・4月・7月・10月） |
| 重大変更後スキャン | インフラ変更・OS更新・nginx設定変更時 |
| スキャン結果レビュー | スキャン完了後1週間以内 |
| CVSS 4.0以上の修正 | スキャン後30日以内 |

### PAY.JPへの確認事項

- [ ] 日本の非保持化加盟店（JavaScript型/iframe型）にASVスキャンは求められるか？
- [ ] PAY.JP側で推奨するASVベンダーはあるか？
- [ ] ASVスキャンレポートの提出先（PAY.JP / アクワイアラ / 不要）
